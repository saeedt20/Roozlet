# Roozlet 0.2.0 — Four seasons on your desktop

A native offline calendar redesigned with Spring, Summer, Autumn and Winter scenes.

- Shamsi date stays centered; Gregorian/Hijri can be hidden independently.
- Automatic Jalali season or manual override; dark/light, custom accent, artwork intensity and Classic mode.
- Adaptive Persian/English sidebar, monthly occasion list, About, and month-title picker.
- Vazirmatn, startup choice, numerical dates, clipboard and all verified annual data remain available.

**Upgrade note:** old appearance settings stay Classic to retain custom colors. Enable Seasonal in Settings → Appearance → Appearance style. The Debian package and command are still `rooz`.

Download `roozlet_0.2.0-1_all.deb`; install with `sudo apt install ./roozlet_0.2.0-1_all.deb`. Verify downloaded assets with `sha256sum -c SHA256SUMS`.

Validation: 44 tests, plus all 14 GTK checks at 200% scaling, on an isolated virtual X11 display. Native Mint installation/upgrade, login, physical multi-monitor and suspend checks were not repeated. See docs/TESTING.md for the exact verification record.

Official Iranian lunar/occasion data still covers 1405 only; unsupported years are labelled rather than guessed. No runtime network connection or wallpaper modification is used.
