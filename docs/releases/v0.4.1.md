# Roozlet 0.4.1 — Seasonal visuals and unified navigation

- Settings, Search and About now stay inside the existing calendar window. Repeated clicks reuse the page; search text and the settings section are preserved. Escape returns to Calendar.
- Persian RTL and English LTR navigation remain native and responsive. Credits and license notices wrap and scroll within the same shell.
- Widget scenery and both seasonal marks reconcile from the same live Shamsi date and appearance preference. Scenic headers also reconcile stale cached season state. Manual theme selection and optional calendar month-following remain supported.
- Existing notes, reminders and preferences are preserved. No calendar/event dataset changes.

## Install or upgrade

Download the Debian package and verify its SHA256SUMS. In the download folder:

```sh
rooz --quit
install -m 644 ./roozlet_0.4.1-1_all.deb /tmp/roozlet_0.4.1-1_all.deb
sudo apt install /tmp/roozlet_0.4.1-1_all.deb
rooz
```

Restarting is required: an older running process retains its imported code and decoded images after a package upgrade. To follow today's season, enable Settings → Appearance → Automatic season. The established package/command name remains `rooz`. The readable /tmp copy avoids the `_apt` home-folder access notice.
