# Roozlet 0.3.1 — About and Credits fixed

Opening Credits no longer makes the window wider than the display. About is now a compact native window with three localized, vertically scrolling pages.

- Long attribution paragraphs and unbroken text wrap within the window.
- Persian headings and controls use RTL; English uses LTR, independently of system translations.
- Explicit GitHub project and issue links replace the generic Website label.
- Native calendar mark and complete original MIT, Vazirmatn OFL, jdatetime PSF and jalali-core LGPL license texts are available offline.
- Existing widget, calendar, settings, seasonal motion, preferences and verified data are preserved.

## Install or upgrade

Download `roozlet_0.3.1-1_all.deb`, then run in its folder:

```sh
rooz --quit
sudo apt install ./roozlet_0.3.1-1_all.deb
rooz
```

Package and command remain `rooz`. Verify downloaded assets with `sha256sum -c SHA256SUMS`.
