Roozlet's first release brings a compact, offline Persian calendar to Linux Mint 22.3 Xfce.

## Highlights

- A 320 × 208 desktop card with Persian, Gregorian and official Iranian Hijri dates.
- Double-click to open a reusable month calendar with occasions, statutory holidays and copy-date actions.
- Persian/English interfaces, independent Persian/Latin digits and bundled Vazirmatn fonts.
- Dark/light themes, appearance controls, position lock/reset and optional always-on-top.
- User-controlled startup at login, off by default.

The project is **Roozlet**. This version retains the application name **Rooz / روز**, command **`rooz`**, and package **`rooz`**.

## Download and install

Download `rooz_0.1.0-1_all.deb` and run in its download folder:

```bash
sudo apt install ./rooz_0.1.0-1_all.deb
rooz
```

Also included: the publication source archive and `SHA256SUMS`. Download all three assets into one folder, then run `sha256sum -c SHA256SUMS` to verify them.

## Verified data

Dataset **1405.1** covers all **365 days** of Persian year 1405, **305 occasion records** and **26 distinct statutory holiday dates**, derived from the final University of Tehran Calendar Center annual calendar.

Official Hijri and annual event coverage is **1405 only** (2026-03-21 through 2027-03-20). Other years display coverage limitations; future lunar holidays are not guessed. Browsing/conversion supports 1350–1450, with all 36,890 days round-trip tested. 190 occasion titles have reviewed English translations; 115 use a clearly labeled Persian fallback.

## Validation and known limits

20 core tests; seven GTK checks at each of normal and 200% scaling; 21 native Mint Xfce interaction checks; installed-layout launches, Persian clipboard checks and reproducible `.deb` builds passed. Real screenshots are included in the README.

X11 is the release target. Real login/suspend/overnight rollover, physical monitor changes, compositor-disabled behavior and package-manager install/upgrade/removal still need desktop acceptance checks. See [the complete validation record](https://github.com/saeedt20/Roozlet/blob/main/docs/TESTING.md).
