# Roozlet 0.3.0 — A calmer calendar and preferences

The compact widget now has matching native calendar and settings windows.

- Scenic month header, lighter day grid and a selected-day card with one Copy date menu, including numerical formats.
- Persian RTL navigation with right-side icons; English LTR navigation with left-side icons. Saturday starts the week in both, and keyboard arrows match the visible direction.
- Grouped preferences, live centered Shamsi preview, seasonal tiles and an advanced section retaining every existing setting.
- Gentle 160–180 ms content fades, a 260 ms scene crossfade and short button feedback. Disable Roozlet transitions in Appearance; native GTK animation preferences are respected. No looping or idle animation.
- Existing widget placement, verified Iranian data, Vazirmatn, independent digits, startup choice and offline operation remain available.

## Install or upgrade

Download `roozlet_0.3.0-1_all.deb`:

```sh
rooz --quit
sudo apt install ./roozlet_0.3.0-1_all.deb
rooz
```

Package and command remain `rooz`. Settings are preserved. Legacy Classic users can enable scenery in **Settings → Appearance → Advanced settings → Appearance style → Seasonal**, or choose a season tile. Verify downloaded files with `sha256sum -c SHA256SUMS`.
