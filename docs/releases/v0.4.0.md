# Roozlet 0.4.0 — Search, notes and reminders

- Search Shamsi/Gregorian dates, Persian/English occasions and your entries. Persian, Arabic and Latin digits are accepted; Ctrl+F/Ctrl+K or Enter jumps directly to the actual day and month.
- Add and edit notes, birthdays, appointments and tasks. Ctrl+N creates an entry for the selected day. Mark an occurrence done and undo deletion.
- One-time, daily, weekly and Shamsi-yearly recurrence, with explicit Esfand leap-day handling.
- Optional desktop notifications, disabled by default: per-entry choice, a global switch, test alert, 24-hour missed-alert catch-up and durable accepted-delivery deduplication.
- Private local SQLite storage, native Persian RTL/English LTR controls and separate personal calendar markers. Existing preferences, official data, seasonal widget and About/Credits improvements are preserved.

**Reminders require Roozlet to be running.** Checks run every 30 seconds; startup remains opt-in. Enable notifications in Notes & reminders or Settings → Desktop & startup, and choose Notify me for each entry. Actual display and click actions depend on the desktop notification service.

## Install or upgrade

Download `roozlet_0.4.0-1_all.deb`, then run in its download folder:

```sh
install -m 644 ./roozlet_0.4.0-1_all.deb /tmp/roozlet_0.4.0-1_all.deb
rooz --quit
sudo apt install /tmp/roozlet_0.4.0-1_all.deb
rooz
```

The readable /tmp copy avoids the `_apt` home-folder access notice. The package and command remain `rooz`; settings and personal entries are preserved. Download all three assets and use `sha256sum -c SHA256SUMS` to verify them.
